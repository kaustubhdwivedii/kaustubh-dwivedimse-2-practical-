MY TASK MANAGER - BEGINNER LEVEL PROJECT
========================================

This is a simple HTML, CSS and JavaScript project for beginners.

HOW TO OPEN:
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The website will open in your browser.

PAGES:
1. Home
2. Dashboard
3. Tasks
4. Calendar
5. Notes
6. Focus Timer
7. Settings

FEATURES:
- Add, edit and delete tasks
- To Do, Doing and Done task columns
- Drag and drop tasks between columns
- Search tasks and filter by priority
- Monthly calendar
- Save and delete notes
- 25-minute focus timer
- Dark mode
- LocalStorage saves tasks, notes and theme in the browser

FILES:
- index.html, dashboard.html, tasks.html, calendar.html, notes.html, focus.html, settings.html
- style.css
- script.js

All pages use the same simple CSS and JavaScript files to make the code easier to understand.
