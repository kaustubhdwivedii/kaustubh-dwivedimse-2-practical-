# Taskflow – Task Manager / Productivity App

A simple productivity web app built with HTML, CSS and JavaScript (no frameworks).

## Pages
Home, Dashboard, Tasks (Kanban), Calendar, Notes, Focus Timer, Settings

## Features
- Add, edit and delete tasks
- Drag-and-drop between To-do / Doing / Done
- Priority filter (High / Medium / Low)
- Pomodoro timer (Focus, Short break, Long break)
- Calendar view of due dates
- Notes with auto-save
- Light / Dark / System theme
- Tasks, notes, theme and settings saved in localStorage

## Run
Open `index.html` in a browser. No install needed.

## Files
- `index.html` – structure
- `style.css` – styling
- `script.js` – app logic
